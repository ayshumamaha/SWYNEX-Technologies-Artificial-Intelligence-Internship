# TASK 1 AI-Based FAQ Question Answering System

## 1. Project Overview

The AI-Based FAQ Question Answering System is a Python application developed as part of the Artificial Intelligence Internship at SWYNEX Technologies. It retrieves answers to common college-related questions from a predefined FAQ dataset using TF-IDF vectorization and cosine similarity.

## 2. Objectives

- Develop a basic FAQ question-answering system.
- Accept questions in natural language.
- Identify relevant FAQ entries using text similarity.
- Retrieve predefined answers.
- Handle unsupported questions using a similarity threshold.

## 3. Technologies Used

- Python
- Scikit-learn
- TF-IDF Vectorizer
- Cosine Similarity

## 4. Features

- Predefined FAQ knowledge base.
- Natural-language question input.
- TF-IDF-based text processing.
- Similarity-based answer retrieval.
- Unanswered question handling.
- Simple command-line interface.

## 5. How to Run

Install the required library:

```bash
pip install scikit-learn
```

Run the Python application:

```bash
python faq_chatbot.py
```
